# 📱 EP003 FIELD SHOOT CARD — SPLIT-SCREEN EPISODE (2 runs, 1–2 days apart)

**⚙️ Phone setup:** Vertical · 4K 60fps · wipe lens · lock focus/exposure · 2–3 takes × 10s
**👕 CRITICAL:** PAREHONG damit sa dalawang run (para patas ang split screen). Iba lang ang sapatos.
**📍 CRITICAL:** Markahan mo ng chalk (o kuhanan ng reference photo) ang EXACT na pwestuhan ng phone — parehong spot sa Run A at Run B. Ito ang buhay ng split screen.
**🕐 Same time of day sa dalawang run** (parehong liwanag). Flat na 3km route.

---

## SETUP SHOT (isang beses lang)

**S — SHOE FACE-OFF 👟👟** — Dalawang pares magkatabi sa gitna ng kalsada, harapan, kamera halos dikit sa lupa. *10s, 2 takes.*

## RUN A — ₱1,500 SHOES (Day 1)

**A1 — SHOE CLOSE-UP** — Suot na, close-up habang naka-tayo/naglalakad. *30cm, 10s.*
**A2 — RUN-THROUGH** — Phone propped sa CHALK MARK. Takbo palayo sa frame, talk-test effort. *3 passes.*
**A3 — WATCH SA LANDMARK** — Pagdating sa napiling landmark (hal. km 2), wrist close-up: pace + HR kitang-kita. *10s.*
**A4 — FOOT STRIKE** — Phone sa lupa, side angle, takbuhan mo 3–4 beses. *Slow-mo material.*
**A5 — ISULAT ANG DATA** — Pagkatapos: average pace, average HR, binti feel 1–10. Screenshot ang watch summary.

## RUN B — CARBON PLATE (Day 2, same time)

**B1–B5 — EXACT REPEAT ng A1–A5.** Parehong chalk mark, parehong landmark, parehong effort (talk test — HINDI habulin ang bilis). Iba lang ang sapatos.

## CASTING CALL SHOT (kahit aling araw)

**C — HERO RUN** — Tumakbo papalapit sa propped phone, neck-down, huminto ang frame sa sapatos. *3 passes.*

---

**❌ FACE RULE:** mukha sa frame = ulitin o ibaba ang anggulo.
**📵 WALANG GIMBAL?** Lahat ng run shots ay propped — hindi mo kailangan. A1/B1/A3/B3: brace elbows.
**⚠️ EFFORT RULE:** Kapag hinabol mo ang bilis sa Run B, sira ang experiment. Talk test sa dalawa.
**✅ DONE WHEN:** S + A1–A4 + B1–B4 + C, tig-2 takes, at nakasulat ang data ng dalawang run.
