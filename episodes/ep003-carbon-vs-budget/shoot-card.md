# 📱 EP003 FIELD SHOOT CARD — SPLIT-SCREEN EPISODE (2 runs, 1–2 days apart)

**⚙️ Phone setup:** Vertical · 4K 60fps · wipe lens · lock focus/exposure · 2–3 takes × 10s
**👕 CRITICAL:** SAME clothes on both runs (so the split screen is fair). Only the shoes change.
**📍 CRITICAL:** Mark the EXACT phone spot with chalk (or take a reference photo) — same spot on Run A and Run B. This is the life of the split screen.
**🕐 Same time of day on both runs** (same light). Flat 3km route.

---

## SETUP SHOT (once only)

**S — SHOE FACE-OFF 👟👟** — Both pairs side by side in the middle of the road, front-on, camera almost on the ground. *10s, 2 takes.*

## RUN A — ₱1,500 SHOES (Day 1)

**A1 — SHOE CLOSE-UP** — Worn, close-up while standing/walking. *30cm, 10s.*
**A2 — RUN-THROUGH** — Phone propped at the CHALK MARK. Run away from the frame, talk-test effort. *3 passes.*
**A3 — WATCH AT LANDMARK** — At the chosen landmark (e.g. km 2), wrist close-up: pace + HR clearly visible. *10s.*
**A4 — FOOT STRIKE** — Phone on the ground, side angle, run past 3–4 times. *Slow-mo material.*
**A5 — WRITE THE DATA** — Afterward: average pace, average HR, leg feel 1–10. Screenshot the watch summary.

## RUN B — CARBON PLATE (Day 2, same time)

**B1–B5 — EXACT REPEAT of A1–A5.** Same chalk mark, same landmark, same effort (talk test — DON'T chase speed). Only the shoes change.

## CASTING CALL SHOT (any day)

**C — HERO RUN** — Run toward the propped phone, neck-down, frame lands on the shoes. *3 passes.*

---

**❌ FACE RULE:** face in frame = reshoot or lower the angle.
**📵 NO GIMBAL?** All run shots are propped — you don't need one. A1/B1/A3/B3: brace elbows.
**⚠️ EFFORT RULE:** If you chase speed on Run B, the experiment is ruined. Talk test on both.
**✅ DONE WHEN:** S + A1–A4 + B1–B4 + C, 2 takes each, and both runs' data written down.
