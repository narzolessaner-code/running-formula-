# 📱 EP008 FIELD SHOOT CARD — Kanin vs Gel (2 runs, 1–2 araw pagitan)

**⚙️ Setup:** Vertical · 4K 60fps · lock exposure · 2–3 takes × 10s
**👕 CRITICAL:** PAREHONG damit sa dalawang run. **📍 CRITICAL:** Chalk mark ang phone spot — parehong pwesto sa dalawang run. **🕐 Parehong oras ng araw.**
**🍚 Protocol:** Run A = 1.5 tasang kanin 2 oras bago. Run B = 1 gel 15 min bago (walang ibang kain).

## SETUP SHOTS (bahay)
**S1 — KANIN HERO 🍚** — Mainit na kanin sa plato, kita ang usok, malapitan. *Bintana light, 2 takes.*
**S2 — GEL HERO ⚡** — Gel packet malapitan, iikot-ikutin sa kamay. *2 takes.*

## RUN A — KANIN DAY
**A1 — KAIN** — Neck-down sa hapag: kamay + kutsara, kumakain ng kanin. *10s.*
**A2 — RUN-THROUGH** — Phone sa chalk mark, takbo palayo, talk-test effort. *3 passes.*
**A3 — WATCH SA KM 4** — Wrist close-up: pace + HR. *10s.*
**A4 — DATA** — Isulat: pace, HR, lakas-feel 1–10. Screenshot ang summary.

## RUN B — GEL DAY (parehong oras)
**B1 — PIGA** — Kamay pumipiga ng gel (bibig hindi kita — piga at kamay lang). *10s.*
**B2–B4 — EXACT REPEAT ng A2–A4.** Parehong chalk mark, parehong effort. HUWAG habulin ang bilis.

## ANYTIME
**C — HERO RUN** — Papalapit sa propped phone, neck-down. *3 passes.*

**❌ FACE RULE:** mukha = ulitin. **⚠️ EFFORT RULE:** talk test sa dalawang run — kapag hinabol mo ang bilis, sira ang test.
**✅ DONE WHEN:** S1–S2 + A1–A4 + B1–B4 + C, tig-2 takes, at kumpleto ang data ng dalawang run.
