## THE PROTOCOL (what the audience does)
- 14 days, 3–4 runs a week, EVERY run at talk-test pace (able to say a full sentence).
- Baseline (Day 0): run until you can no longer say a full sentence — record how many minutes/kilometers before that happens. PHONE TIMER ONLY.
- Day 14: repeat the same baseline test. Comment both numbers.
- You join too — you're Lab Rat #1, they're Lab Rats #2 to #500.
